# Cyber-Engineering Visual Design System

## 1. Design Philosophy

The visual identity for Ravi Ranjan Singh's GitHub profile is designed as a dark, futuristic cyber-engineering environment that communicates architectural depth, systems-level rigor, and production reliability.

## 2. Color Tokens

The visual assets strictly adhere to this verified palette:

- **Primary Background**: `#05080B` (Deep Obsidian Void)
- **Secondary Background**: `#0A0C10` (Dark Technical Panel)
- **Primary Accent**: `#00FF88` (Emerald Neon)
- **Secondary Accent**: `#00D9FF` (Cyan Telemetry Glow)
- **Auxiliary Accent**: `#8B5CF6` (Violet Quantum Edge)
- **Text Primary**: `#F5F7FA` (High-Contrast Clean White)
- **Text Secondary**: `#AAB7C4` (Muted Technical Slate)

## 3. Typography & Monospace Accents

- **Display Headings**: Clean system geometric sans-serif (`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Arial, sans-serif`).
- **Telemetry & Labels**: High-precision monospace font stack (`'JetBrains Mono', Menlo, Consolas, monospace`) with uppercase tracking (0.8px – 2px).

## 4. Layout Dimensions & ViewBox Ratios

Every vector visual asset maintains a strict 1200px width for responsive rendering across mobile, desktop, and 4K displays:

- **Hero Banner (`hero.svg`)**: 1200 × 380 (Aspect Ratio: 3.158)
- **Architecture Diagram (`architecture.svg`)**: 1200 × 480 (Aspect Ratio: 2.500)
- **Expertise Taxonomy (`expertise.svg`)**: 1200 × 540 (Aspect Ratio: 2.222)
- **Featured Projects (`projects.svg`)**: 1200 × 580 (Aspect Ratio: 2.069)
- **Engineering Footer (`footer.svg`)**: 1200 × 220 (Aspect Ratio: 5.455)
- **Section Divider (`divider.svg`)**: 1200 × 24 (Aspect Ratio: 50.000)

## 5. Visual Hierarchy & Reticles

- All container panels utilize technical corner reticles (sharp 90° brackets or subtle quadrant curves).
- Subtle background patterns utilize 25px or 30px technical grid lines with 0.05 opacity and micro-dots.
